# Anonimato digital

Skill de OpenCode para revisar qué datos compartes al navegar y usar servicios de IA desde Windows o WSL2. Cubre la IP pública, los permisos de ubicación, la telemetría, las sesiones del navegador y la sincronización de archivos.

Abre el repositorio como proyecto en OpenCode y escribe «Usa @anonimato-digital para revisar qué datos comparto al usar un chat de IA desde mi navegador».

Para usarla en otro proyecto, copia la carpeta completa `.opencode/skills/anonimato-digital` a la misma ruta de ese proyecto.
